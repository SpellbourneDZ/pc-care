# SPE-56 — desktop UX и дизайн-система

## Граница

Четыре интерактивные React-оболочки: Умная очистка, Диски, Автозагрузка, Программы. Это **прототип**: постоянная полоса помечает данные примера, а каждое подтверждение поясняет отсутствие системных изменений. Overview и история начинаются без вымышленных результатов. Системный IPC, сканеры и действия здесь не подключаются.

Порядок по последнему указанию владельца: SPE-56 → SPE-57 → SPE-60. Сохранение настроек, поиск по всему приложению и рабочая маршрутизация — SPE-57; реальные UX-модули развиваются в SPE-62/66/72/75 вместе с соответствующими backend issue.

## Визуальный контракт

Спокойный рабочий интерфейс Windows: постоянная sidebar, компактные строки, один основной action, выбор перед подтверждением. Никаких health scores, обещаний ускорения или декоративных метрик. На обзоре — начало анализа и три перехода к инструментам.

Все цвета, включая ошибки, риски, focus и выделение, — белый/чёрный/серые. Safe/Review/Protected различаются текстом и Lucide-иконками. Отдельный control-border обеспечивает контраст controls, не утяжеляя декоративные разделители. Тест проверяет монохромность, контраст текста ≥4.5 и заданных границ/focus ≥3; это не заявление о полной сертификации WCAG.

Шрифт — локальный Segoe UI Variable / Segoe UI, без загрузки из сети. Роли: заголовок страницы 26/600, пустое состояние 18–21/600, основной текст 14, строки таблиц 13, метаданные 12. Числа с tabular-nums; неизвестные размеры/даты остаются «—»/«Нет данных». Ритм 4/8/12/16/24/32 px, panel inset 16–32; радиусы 4/6/8/12 px. Кнопки одной роли — 32 px, навигация 38 px, sidebar 220 px, инспектор 260 px.

Light/dark/system переключаются сразу; system реагирует на изменение ОС. В SPE-56 выбор живёт в памяти. Reduced motion отключает анимацию, keyboard focus явно обведён. При узком окне sidebar превращается в Sheet; таблицы прокручиваются внутри области, footer с действием остаётся доступен. Минимум приложения — 720×520, стартовое окно — 1280×720.

## Компоненты

Основа — официальный shadcn CLI 4.22.1, Radix Nova, существующий radix-ui. Sidebar/Sheet/Tooltip, Button/Card, Checkbox/Switch, Table, AlertDialog/Dialog, Select/Tabs, Breadcrumb/Input/Badge, Progress/Skeleton/ScrollArea находятся в `src/ui`. Вторая UI-библиотека не создаётся; уведомления в этих flows — встроенный status, отдельный toast не нужен.

Кастомизации: semantic монохромные tokens, RU accessible labels, focus/reduced motion, размеры, `useSyncExternalStore` для media query без лишнего render из effect, sidebar без cookie persistence. Controlled Switch сохраняет собственный checked data-state при использовании как trigger диалога. Progress передаёт value в Radix Root, включая indeterminate.

Production CSP сохраняется строгой, без unsafe-inline. Tauri подставляет per-response style nonce в meta `pc-care-style-nonce`; main передаёт его библиотеке `get-nonce` перед render. Radix singleton styles и Viewport Select/ScrollArea получают этот nonce. `get-nonce` 1.0.1 уже был транзитивной зависимостью; добавлен прямой pinned импорт для этого API. Native smoke проверяет отсутствие CSP errors при открытии overlays.

## Взаимодействия

| Модуль       | Оболочка и подтверждение                                                                                                                                                                                                                                         |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Очистка      | Выбор категорий, точная сумма примера, disabled Protected, список выбранного в AlertDialog. Общий checkbox выбирает только Safe; Корзина — отдельный ручной checkbox. Отмена сохраняет выбор, подтверждение показывает явно условный отчёт.                      |
| Диски        | Переключение карты/дерева, выбор объекта и инспектор path/risk/logical size; неизвестный size-on-disk не придумывается. Protected нельзя отправить в Корзину. Карта — фиксированная layout fixture с согласованными размерами; реальный treemap engine — SPE-66. |
| Автозагрузка | Source/publisher/status, системный/неизвестный источник read-only. Switch меняется только после подтверждения; отмена не меняет состояние. Никакого реального registry/startup эффекта.                                                                          |
| Программы    | Фильтрация примеров, сведения, вложенное подтверждение штатной деинсталляции. Остатки — отдельный шаг с предупреждением об evidence/confidence и резервировании реестра. Ничего не выбирается/удаляется автоматически.                                           |

В каждом модуле доступны empty/loading/error/partial/unsupported/offline/ready. Empty предлагает анализ; loading отменяется без публикации отложенного результата; error предлагает повтор; partial сохраняет доступный результат и поясняет пропуски; unsupported запрещает действия; offline не блокирует локальные инструменты. Пример анализа — отменяемый локальный timer, не backend scan.

## Проверка

Клавиатура: skip-link, semantic navigation/aria-current, именованные checkbox/switch/select, Tabs, Escape/cancel, modal focus trap и возврат focus к trigger. Browser checks проходят при 1280×720, 1920×1080 и 720×520, также с DPR 1.25/1.5. Это browser DPI emulation, а не смена Windows display scaling.

Настоящий release EXE проверяется в Windows WebView2 offline: четыре модуля, confirmations, protected/read-only, вложенный Dialog/AlertDialog, CSP и закрытый IPC. Тесты не изменяют пользовательские файлы/реестр. Чистые Windows 10/11 VM и настоящая смена OS DPI — отдельная проверка; browser smoke её не заменяет.
